Read and download the report

Start with the totals. Then open the part of the report that explains the number you want to check.

Read the report from top to bottom

  1. Check the file names and As-of Date so you know which comparison you are reading.
  2. In Overall result, read the totals and the list of filters used. This tells you whether you are looking at all rows or a smaller selection.
  3. Open New Books to see items present in the comparison file that were absent from the starting file. These are new records. Check Attribute changes, or the named comparison sections, to see changes on matching rows. In Baseline shows the starting value and In Comparison shows the value in the file you checked.
  4. Use Exception Rule Summary to see the counts by check. Open a rule’s section to see why rows were flagged. Use the combined Exception Table to review items across checks.
  5. Use the table filters to narrow a long list. If a row seems to be missing, clear the table filters and check New Exceptions Only. When ticked, it shows new and returning items that still need an explanation. Untick it to also see items that already have one.

Use the Exception ID to find the same flagged item in the report, the tracking list, and the Excel sheet for explanations.

Download a copy

  1. To rename the report, double-click its name, type the new name, and press Enter.
  2. Set New Exceptions Only for the items you want to include in the report copy.
  3. Click Export HTML to save a report you can open in a browser. Click Export Excel to save an Excel report.
  4. To collect explanations, click Download commentary template. It covers items from this report, including those that already have explanations. Follow the steps for filling in and returning the sheet.
  5. Find the downloaded file in your browser’s downloads list or in the folder where you chose to save it.

To reopen a saved report later, use History. For an older report without an As-of Date, the commentary button is unavailable.
