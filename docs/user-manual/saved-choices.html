Save and reuse your choices

A “config” is a named set of choices you can use again the next time you compare files.

Find the two places to save

  • Load config for rows and columns is on the upload screen after the files are inspected and on 2. Compare and validate. It saves choices such as how to match rows, filters, and columns to show. Save from step 2 after finishing those choices.
  • Load config for rules is in Validation rules. Use it to save which checks you want to run. Use Save rule inside the rule editor when changing the check itself.

Save your choices for the first time

  1. Open the matching area and click Save to new config.
  2. Enter a name you will recognize, such as Month-end rows and columns or Month-end checks, and confirm.
  3. To update a saved set, select its name, click Save to config, then confirm that you want to replace the saved choices.

Use saved choices with your next files

  1. Upload the files for the new report and inspect their column names.
  2. In Load config for rows and columns, select the saved name and click Load config. If asked to discard current changes, confirm only if you are ready to replace them.
  3. Read any messages about columns or other choices the app could not use. Check the way rows are matched, the filters, and the report columns.
  4. Under Validation rules, open Load config for rules, select the saved name, and click Load config. Check the list of rules selected for this report.
