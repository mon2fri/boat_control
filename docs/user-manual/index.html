Boat Control user manual

Use this guide to compare two files, check for problems, and record your explanations in Excel.

Start here

  1. Upload your files

    Choose the two files and tell Boat Control how to match their rows.

  2. Choose rows and columns

    Decide what to include, what to compare, and what to show.

  3. Save and reuse your choices

    Keep the same setup for your next report.

  4. Set up checks and run the report

    Choose what must be true and what to flag for review.

  5. Read and download the report

    Find changes and flagged items, then save a browser or Excel copy.

  6. Make reusable lists

    Pick several columns or several entries by choosing one list.

  7. Track flagged items and add explanations

    Find issues by date, understand their labels, and return the completed Excel sheet.

Bold words in the instructions match labels you can look for on the screen. An exception is an item that a check flagged for review.
