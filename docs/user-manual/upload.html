Upload your files

Choose a starting file and the file you want to check against it.

Pick the date and the two files

  1. Open 1. Upload.
  2. Under Exception tracking date, set As-of Date to the date your report is for. Check the date even if one is already filled in. You will use it again when looking up flagged items.
  3. Under Source type, choose Local upload to use files on your computer. The files should end in .csv.
  4. In Baseline, choose the starting file, usually the older one. In Comparison, choose the file you are checking, usually the newer one.
  5. Click Inspect headers and wait for the app to show the column names. Check the two names under Loaded files. Use Replace files if you picked the wrong one.

If your team has already set up a shared file location in Boat Control, choose Remote source, pick the location, and choose both files from the lists.

Tell Boat Control how to match rows

  1. Under Select columns to include, keep the columns you will need for matching, filtering, checking, or showing in the report.
  2. Under Key columns (record identity), choose the column that identifies the same item in both files. For example, use Account Number if each number appears only once per file. If a number repeats across branches, you might need both Branch and Account Number.
  3. Click Validate key columns if shown. If the app reports a problem, check your choices and try again.
  4. Click Continue to compare & validate.

If you already have a saved setup, you can use Load config for rows and columns after the column names appear. Review the choices it fills in before continuing.
