Choose rows and columns

Open 2. Compare and validate. Start by deciding which rows belong in this report.

Choose which rows to include

  1. Open Row filters and click + Add filter. To include all rows, leave the list empty.
  2. Choose a Column, how to check it, and a Value. For example, choose Region, equals, and Singapore to include Singapore rows.
  3. To add another choice, click + Add filter again. Under Combining Filters with, choose AND — all must match if every line must be true, or OR — any may match if one matching line is enough.
  4. For a mix, choose CUSTOM GROUPS — nested groups. Put related lines together and choose whether all or any must match at each level. For example, require Status is Open and put Region is Singapore and Region is Malaysia in a group where either can match. Read the preview before continuing.

When you pick several entries on one line, equals and contains accept a match with any of them. The negative choices exclude rows matching any of the picked entries. An empty cell passes the negative checks.

Choose what to compare and what to show

  • Track Changing Columns controls which columns to check for changes. Leave it empty to use all the columns selected during upload.
  • Attribute Comparing Sections lets you break the changes into named parts. Click Add section, enter a name such as Status changes, choose the columns, and add the section. Without sections, changes appear together.
  • Extra Columns adds context, such as Owner. These choices are available in the combined Exception Table. Use Display Extra Columns In to choose other places to show them.
  • Extra Columns for Commentary Template chooses what to include beside the explanations in the Excel sheet. Pick these separately. For example, add Owner so reviewers can see who should explain each item.

To show counts by a column such as Region, go back to 1. Upload and use Select aggregation columns. If you want a breakdown such as branches within regions, put Region first and turn on Enable nested aggregation.
