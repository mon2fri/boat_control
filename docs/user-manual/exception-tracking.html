Track flagged items and add explanations

Exception Tracking shows what was flagged for a reporting date and which items still need an explanation.

Find the items for a date

  1. Open Exception Tracking and choose the same As-of Date you used for the report.
  2. If the date is missing from the short list, choose Other date… and look in the calendar. Dates with a green dot have tracking data.
  3. Use Columns above the table to show more details. Use the column headings to sort or filter the list. Filtered total counts the items that match your table filters. All rows is the total for the date.
  4. Use Refresh dates and list if you have just run a report and its date is missing. Use Refresh list to check for updated explanations.

Read the exception labels

New
This is the first recorded date for the item, and it has no explanation.
Commented
The item has an explanation. Read it in the Commentary column.
NotCommented
The item was seen before and still has no explanation for the selected date.

Exception ID identifies the flagged item. Rule Index tells you which check flagged it. When sharing a question about an item, give its date and Exception ID.

Download, fill in, and return the Excel sheet

  1. Click Download commentary template in Exception Tracking for the whole selected date. To work on the items from one report, use the same button on that report’s Results page.
  2. Open the downloaded file in Excel. Check the date on the Template sheet. Go to the Exceptions sheet and type your explanations in Commentary.
  3. Edit only Commentary. Keep existing text you still need. Leaving a cell empty clears the saved explanation for that item on that date. Keep the original sheet names, rows, and IDs, and save the file as .xlsx.
  4. Return to Exception Tracking and select the date shown in the Excel file. Under Upload completed commentary template (.xlsx), choose your saved file.
  5. Wait for confirmation, then check the list for your explanations and the Commented label. If the app reports a problem, read its message and check the date and file. If you need a fresh copy, download one for the same date or report and transfer just your commentary using the Exception IDs.
