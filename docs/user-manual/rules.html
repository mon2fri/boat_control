Set up checks and run the report

A rule says what should be true. When a row the rule applies to fails the check, it appears as an exception.

Add or edit a rule

  1. Open Validation rules on 2. Compare and validate. Click + Add rule to create one, or open an existing rule for editing.
  2. Give the check a name people can understand, such as Open accounts must be marked active. Add a description if it helps explain what to review.
  3. Use Conditions (optional) to limit who gets checked. For example, add a condition where Account Status equals Open. Leave this area empty to check every row included in the report that the rule can check.
  4. Under Logic (required), say what must be true. Choose Value against column to check a column against an entry, such as Status must equal Active. Choose Column against column to check against another column or against the starting file, using the choices shown.
  5. If several expectations appear, decide whether all must be true or any one can be true. Use the grouping options to combine choices when you need a mix, and read the preview before saving.
  6. Under Extra columns to display, add details reviewers need for this check. Leave Hide comparison columns clear if people need to see the values being checked.
  7. Click Save rule.

Run your checks

  1. Under Select rules for this run, tick the rules you want. Check for selections on other pages if the list spans several pages.
  2. Click Run comparison and validation. On 3. Results, check the selected rules and click Run now.
  3. Wait for the results. If the app asks you to confirm that all rows should be checked, confirm only if that is the report you want.
